# Mini Order Management Application

## Overview

A Mini Order Management REST API built using C# and .NET 10, 
following Clean Architecture, Domain-Driven Design (DDD), CQRS, SOLID principles, 
Repository Pattern, and Unit of Work.

## Technology Stack

- .NET 10
- ASP.NET Core Web API
- Entity Framework Core 10
- SQL Server
- MediatR
- FluentValidation
- xUnit
- Moq
- Swagger / OpenAPI

## Architecture

The application follows Clean Architecture with the following layers:

- API
- Application
- Domain
- Infrastructure
- Tests

## Project Structure

MiniOrderManagement
├── MiniOrderManagement.API
├── MiniOrderManagement.Application
├── MiniOrderManagement.Domain
├── MiniOrderManagement.Infrastructure
└── MiniOrderManagement.Tests
